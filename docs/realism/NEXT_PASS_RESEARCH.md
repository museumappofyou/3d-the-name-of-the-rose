# Updated web research — candidates for the next pass

Checked 29 September 2026 against source pages, expanded after the independent re-audit. These are **candidates**, not downloaded or integrated packages. Source-page verification does not establish that their rigs, clips or meshes pass in-game inspection. Preserve artist names, original URL, exact licence and derivative/attribution text in the existing source lists if adopted. Sketchfab supplies a converted glTF for downloadable models ([format policy](https://sketchfab.com/features/gltf)); inspect the actual package. Free means no listed price; sign-in may be needed. Optimise maps and LODs for the current browser budget; the earlier ~20 ms scriptorium measurement is Agent A's benchmark, not a fresh result.

**Selected first trials:** irregular sack, textured sheep, and one complete human using a CC0 MakeHuman body plus Donitz robe. **Optional:** basket or period reliquary for a genuinely weak foreground prop, and a sparse rights-clear vocal texture. Paid Fab characters remain conditional: no price or exact selected licence was established, and no purchase is authorized by this audit. Existing camera/role/hour bugs need code fixes before importing more assets.

[Obsidian's official Pentiment gallery](https://pentiment.obsidian.net/) supports manuscript framing and readable text/settings as an aesthetic reference. It is a sixteenth-century illustrated game, so copy neither its period assumptions nor proprietary art. [Inkle's Heaven's Vault design explanation](https://medium.com/@inklestudios/why-does-translation-unlock-sites-in-heavens-vault-e05c4ccadf62) demonstrates how interpreting an object can suggest another place. **Design inference for this abbey:** a catalogue mark, route or view relation should create curiosity; use a few remembered observations, not that game's complete translation/narrative system. References only, no reusable game assets.

## Selection rule

Start with **one sheep, one sack and one close human** in a controlled in-game comparison. Judge front/side/back at player distance, light match, motion, foot/floor contact, download rights, memory and frame time. Keep an asset only if it improves the whole scene. Reject model packs whose style is more modern/fantasy than the present abbey, or whose page's licence badge conflicts with its text. No ripped game content, NC/ND sources or ambiguous personal-use demos.
